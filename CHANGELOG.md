# Changelog

All notable changes to the public reproducibility package are documented here.

## 1.0.0 - 2026-09-22

Initial public release.

### Included

- NegativeKANNeXt architecture construction.
- Patient-level train/validation/test splitting.
- Training-only augmentation.
- SGDM training configuration.
- Held-out patient-level evaluation.
- GAP feature extraction.
- CWINCA-based feature selection.
- Six shallow DFE classifiers.
- Repeated patient-level cross-validation workflow.
- Calibration utilities.
- Core ablation utilities.
- Frozen-model external-validation entry point.
- Grad-CAM and occlusion-sensitivity utilities.
- Representation-analysis utilities.
- Analytic parameter-count audit.
- Reproducibility and implementation-scope documentation.
